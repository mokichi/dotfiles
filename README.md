# mokichi's dotfiles

## Requirements

- zsh
- oh-my-zsh
- homebrew

## Install

```
git clone git@github.com:mokichi/dotfiles.git ~/Work/mokichi/dotfiles
git clone git@github.com:mokichi/dotfiles-private.git ~/Work/mokichi/dotfiles-private  # optional (private)
export PATH=/opt/homebrew/bin:$PATH
brew bundle
RCRC=~/Work/mokichi/dotfiles/rcrc rcup
```

## Update

```
rcup
```
